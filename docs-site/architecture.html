Architecture

Three-tier platform design with security at every layer.

System overview

┌─────────────┐ HTTPS ┌──────────────┐ franz-go ┌─────────────┐ │ Browser │ ─────────────► │ React UI │ │ │ │ (no Kafka) │ ◄───────────── │ (nginx) │ │ Kafka │ └─────────────┘ └──────┬───────┘ │ Cluster │ │ REST / JWT │ │ ▼ └──────▲──────┘ ┌──────────────┐ │ │ Go API │ ──────────────────────┘ │ (chi router)│ └──────┬───────┘ │ SQL ▼ ┌──────────────┐ │ PostgreSQL │ │ metadata · │ │ audit · IAM │ └──────────────┘
Critical security property: The browser never connects directly to Kafka. All cluster credentials are encrypted at rest and used only by the backend.

Components

Frontend (React + TypeScript)

  • Vite build tooling with HMR for development
  • TanStack Query for server state and caching
  • Tailwind CSS with dark/light theme support
  • Recharts for dashboard visualizations
  • React Router for client-side navigation

Backend (Go)

  • chi HTTP router with middleware (CORS, JWT, request ID)
  • franz-go (github.com/twmb/franz-go) for Kafka admin, consume, produce
  • PostgreSQL via pgx connection pool
  • bcrypt password hashing, JWT session tokens
  • AES-GCM encryption for cluster SASL passwords
  • Prometheus metrics at /metrics

PostgreSQL

Stores all platform metadata:

  • Users, roles, permissions (database-backed RBAC)
  • Cluster connection configs (encrypted secrets)
  • Audit log entries for sensitive operations
  • Session invalidation via token_version

Request flow

  1. User authenticates via POST /api/v1/auth/login → receives JWT
  2. Frontend attaches Authorization: Bearer <token> on every API call
  3. Backend middleware validates JWT and loads user permissions from PostgreSQL
  4. Route handler checks required permission before executing
  5. Kafka operations resolve cluster config, decrypt credentials, open franz-go client
  6. Mutations (publish, create topic, etc.) are recorded in the audit log

Multi-cluster model

Each cluster record stores bootstrap servers, optional SASL/TLS configuration, and environment label. The backend resolves connections per request — credentials are never sent to the browser or logged in plaintext.

Data flow — RBAC

PostgreSQL (roles, permissions, role_permissions) ↓ Go store / API (GetRolePermissions) ↓ JWT login + /me endpoint ↓ React UI (Roles editor, user dropdowns, route guards)
