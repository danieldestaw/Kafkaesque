Features

Everything included in Kafkaesque v0.1.

Cluster management

  • Register multiple Kafka clusters with encrypted credentials
  • Test connection before saving
  • Environment labels: Development, Staging, Production
  • Cluster selector in the header with live connection status
  • Shared Docker network support for co-located services

Brokers & topics

  • List brokers with leader partition counts and rack info
  • List, create, and delete topics
  • Partition inspection with leader/replica details
  • Internal topics filtered from user-facing views

Messages

  • Browse messages by partition with offset navigation
  • Produce messages with key, value, and headers
  • Values rendered as plain text (never HTML — XSS safe)
  • All publish operations audited

Consumer groups

  • List groups with state, members, topic count
  • Total lag and max lag per group
  • Detail drawer with lag warnings
  • Offset reset (permission-gated)

Dashboard

  • Six KPI cards: Brokers, Topics, Partitions, Consumer Groups, Under-Replicated, Offline Partitions
  • Cluster Metrics area chart (30-minute history)
  • Cluster Health donut with operational checklist
  • Top Topics by Messages donut chart
  • Recent Activity from audit log
  • Cluster Load: partition density, consumer lag, replication stress
  • Live refresh with last-updated timestamp

Identity & access

  • User CRUD with enable/disable and soft delete
  • Password reset (admin) and self-service password change
  • Session revocation via token version increment
  • Database-backed roles and permissions (editable in UI)
  • Default roles: Admin, Operator, Developer, Viewer
  • Per-user audit history

Audit & observability

  • Full audit log for login, topic, message, and admin operations
  • Notification bell with unread activity count
  • Global search command palette (⌘K)
  • Prometheus metrics endpoint on backend

UI/UX

  • Dark and light mode with persisted preference
  • Responsive layout with collapsible sidebar
  • Modern login page with theme toggle
  • Toast notifications and confirmation dialogs
