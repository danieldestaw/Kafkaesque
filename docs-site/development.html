Development

Run backend and frontend locally outside Docker.

Prerequisites

  • Go 1.23+ for the backend
  • Node.js 20+ and npm for the frontend
  • PostgreSQL 16 (or use Docker for DB only)

Database only via Docker

docker compose up -d streamforge-db

Backend

cd backend

export DATABASE_URL="postgres://streamforge:streamforge@localhost:5433/streamforge?sslmode=disable"
export JWT_SECRET="dev-streamforge-secret"
export ENCRYPTION_KEY="0123456789abcdef0123456789abcdef"
export HTTP_PORT=8090
export CORS_ORIGINS="http://localhost:5173"

go run ./cmd/streamforge

Migrations run automatically on startup.

Frontend

cd frontend
npm install
npm run dev

Vite dev server runs at http://localhost:5173 with API proxy to the backend.

Running tests

cd backend
go test ./...

Project structure

streamforge/
├── backend/
│   ├── cmd/streamforge/     # Entry point
│   └── internal/
│       ├── api/             # HTTP handlers & router
│       ├── auth/            # JWT & login
│       ├── authorization/   # RBAC helpers
│       ├── kafkaclient/     # franz-go wrapper
│       ├── storage/         # PostgreSQL store & migrations
│       └── crypto/          # AES-GCM encryption
├── frontend/
│   └── src/
│       ├── pages/           # Route pages
│       ├── components/      # UI components
│       ├── api/             # API client
│       └── stores/          # Auth state
├── docs-site/               # This documentation (static)
└── docker-compose.yml
