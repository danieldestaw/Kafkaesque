Getting Started

Launch Kafkaesque locally and connect your first Kafka cluster.

Prerequisites

  • Docker and Docker Compose v2+
  • An Apache Kafka cluster (optional — use banking-service or any reachable broker)
  • Ports 3100 (UI) and 8090 (API) available on localhost

1. Start the platform

Clone the repository and start all services:

git clone https://github.com/streamforge/streamforge.git
cd streamforge
docker compose up -d --build

This starts three containers:

ServicePortDescription
frontend3100React UI served by nginx
backend8090Go REST API
streamforge-db5433PostgreSQL metadata store

2. Sign in

Open the UI and authenticate with the default bootstrap account:

http://localhost:3100
FieldValue
Username / emailadmin
Passwordadmin
Change default credentials in production. Set DEFAULT_ADMIN_USER and DEFAULT_ADMIN_PASS environment variables before first boot, and rotate secrets after deployment.

3. Add a Kafka cluster

  1. Navigate to Clusters in the sidebar
  2. Click Add Cluster
  3. Enter a display name (e.g. Banking Kafka)
  4. Set bootstrap servers (e.g. kafka:9092 for Docker networks)
  5. Choose environment: DEVELOPMENT, STAGING, or PRODUCTION
  6. Test connection, then save

4. Verify the dashboard

After connecting a cluster, open the Dashboard to confirm:

  • Broker, topic, and partition counts appear in KPI cards
  • Cluster Metrics chart renders with live data
  • Cluster Health shows HEALTHY status
  • Top Topics donut chart lists your topics
  • Recent Activity shows audit events

Acceptance checklist

  1. Login at http://localhost:3100
  2. Add cluster with valid bootstrap servers
  3. Verify brokers, topics, and consumer groups pages load
  4. Browse messages on a topic with traffic
  5. Publish a test message and confirm it appears in the audit log
