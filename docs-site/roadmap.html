Roadmap

Planned features and release milestones.

v0.1 — Current

  • Authentication and JWT sessions
  • Database-backed RBAC with user and role management
  • Multi-cluster management with encrypted credentials
  • Topics, messages, consumer groups, brokers
  • Live dashboard with health metrics and cluster load
  • Audit logging and notification feed
  • Command palette (⌘K)
  • Dark/light mode
  • Docker Compose deployment
  • banking-service Kafka integration

v0.2

  • Schema Registry integration
  • Kafka Connect management
  • WebSocket live message tail
  • Enhanced command palette actions

v0.3

  • ACL management
  • Alert rules and notifications
  • Prometheus dashboards

v0.4

  • Helm chart and Kubernetes manifests
  • Plugin architecture
  • OIDC / SSO authentication
Roadmap items are subject to change. Contributions and feature requests are welcome on the project repository.
