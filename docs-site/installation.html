Installation

Docker Compose deployment and environment configuration.

Docker Compose (recommended)

The fastest path to a running instance:

cd streamforge
docker compose up -d --build

Networks

Docker Compose defines two networks:

  • streamforge-net — internal bridge for UI, API, and database
  • banking-net — external network (banking-service_banking-net) for Kafka access
The database service is named streamforge-db (not postgres) to avoid DNS conflicts when sharing networks with banking-service.

Verify installation

# API health
curl http://localhost:8090/health

# Login
curl -X POST http://localhost:8090/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"admin","password":"admin"}'

Stop and reset

docker compose down          # stop containers
docker compose down -v       # stop and remove volumes (resets DB)
