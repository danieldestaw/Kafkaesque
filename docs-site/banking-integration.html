Banking Service Integration

Connect Kafkaesque to the banking-service Kafka cluster.

Kafkaesque is designed to operate alongside the banking-service project, sharing a Docker network to reach the Kafka broker without exposing it on localhost.

Prerequisites

  1. banking-service Kafka is running
  2. Docker network banking-service_banking-net exists
  3. StreamForge backend is attached to that network (configured in docker-compose.yml)

Network configuration

The StreamForge docker-compose.yml declares an external network:

networks:
  banking-net:
    external: true
    name: banking-service_banking-net

The backend service joins both streamforge-net and banking-net.

Use Docker DNS, not localhost. Inside Docker, bootstrap servers must be the Kafka service name (kafka:9092), not localhost:9092.

Step-by-step

  1. Start banking-service Kafka: 
    cd banking-service
docker compose up -d
  2. Start StreamForge: 
    cd streamforge
docker compose up -d --build
  3. Open http://localhost:3100 and sign in (admin / admin)
  4. Go to Clusters → Add cluster:
    FieldValue
    NameBanking Kafka
    Bootstrap serverskafka:9092
    EnvironmentDEVELOPMENT
  5. Test connection, save, and select the cluster from the header dropdown

Expected topics

After connecting, you should see banking-service topics such as:

  • user-events
  • order-events
  • payment-events

These appear in the dashboard Top Topics chart and on the Topics page.

Troubleshooting

IssueSolution
Connection refusedVerify banking-service is running and network name matches
Network not foundStart banking-service first to create banking-service_banking-net
Empty dashboardSelect the cluster from the header dropdown
DNS conflict with postgresStreamForge DB is named streamforge-db intentionally
