Kafkaesque (StreamForge) is an open-source platform for managing, monitoring, and operating Apache Kafka clusters — with RBAC, audit logging, and a modern dashboard.

Get Started → Architecture

🚀 Quick Start

Run with Docker Compose and sign in with the default admin account in under five minutes.

🏗 Architecture

Three-tier design: React UI, Go API, PostgreSQL metadata — the browser never talks to Kafka directly.

🔐 RBAC & IAM

Database-backed roles and permissions with Admin, Operator, Developer, and Viewer defaults.

📊 Dashboard

Real-time KPIs, cluster health, topic distribution, activity feed, and cluster load metrics.

🏦 Banking Service

Connect to the banking-service Kafka cluster over a shared Docker network.

📡 API Reference

REST API for clusters, topics, messages, consumer groups, users, roles, and audit logs.

What is Kafkaesque?

Kafkaesque provides a unified control plane for Apache Kafka. Operators and developers can manage multiple clusters, inspect brokers and partitions, browse and produce messages, monitor consumer lag, and review audit trails — all through a secure web interface.

The backend is written in Go using franz-go for native Kafka connectivity. The frontend is a React + TypeScript SPA with TanStack Query, Tailwind CSS, and dark/light mode support.

Key capabilities

  • Multi-cluster management with encrypted credentials (server-side only)
  • Topics: list, create, delete, partition inspection
  • Message browser and producer with audit logging
  • Consumer groups and lag monitoring
  • Live dashboard with cluster health metrics
  • User management, session revocation, password reset
  • Editable roles and permissions stored in PostgreSQL
  • Command palette (⌘K / Ctrl+K)
