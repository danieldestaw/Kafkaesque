Deployment

Production considerations and deployment options.

Docker Compose (development / staging)

The included docker-compose.yml is suitable for local development and small staging environments:

docker compose up -d --build

Production checklist

  • Replace JWT_SECRET with a cryptographically random value (≥ 32 bytes)
  • Replace ENCRYPTION_KEY with a unique 32-byte hex key
  • Set strong DEFAULT_ADMIN_USER and DEFAULT_ADMIN_PASS before first boot
  • Use managed PostgreSQL with TLS and backups
  • Configure CORS_ORIGINS to your production domain only
  • Place the API behind a reverse proxy with TLS termination
  • Restrict network access to Kafka brokers (VPN or private network)
  • Enable Prometheus scraping of /metrics
  • Review and rotate cluster credentials periodically

Frontend build

The frontend is a static SPA built with Vite and served by nginx in Docker:

cd frontend
npm ci
npm run build
# Output: frontend/dist/

The nginx config proxies API requests to the backend service.

Backend build

cd backend
go build -o streamforge ./cmd/streamforge
./streamforge

Deploy documentation to Vercel

This documentation site is a static HTML/CSS/JS site in the docs-site/ directory:

cd docs-site
npx vercel --prod

Or connect the repository to Vercel and set the root directory to docs-site.
